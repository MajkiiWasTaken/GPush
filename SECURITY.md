# Security Policy

## Supported Versions

Security fixes are provided for the latest stable GPush release.

| Version | Supported |
| ------- | --------- |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x: |

## Reporting a Vulnerability

If you discover a security issue in GPush, please do not publish it immediately in a public issue.

Report it privately through GitHub Security Advisories:

**Repository -> Security -> Advisories -> Report a vulnerability**

Please include:

- affected GPush version
- operating system
- steps to reproduce the issue
- expected and actual behavior
- any relevant logs or screenshots

Security reports will be reviewed as soon as possible.

If the issue is confirmed, a fix will be prepared and released before the vulnerability is publicly disclosed.

If the report is not considered a security vulnerability, it may be redirected to a normal GitHub issue.
